# Graph

## Types :
1. Undirected Graph - edges do not direct to nodes, they are connected undirected
2. Directed Graph - edges direct to nodes
3. Weighted Graph - edges carry some weight

## Terminology :
1. Node - a element contanning some info,data,etc
2. Edge - connection between nodes

## Examples
1. Flight Route - Directed Graph
2. Facebook - Undirected Graph
3. Google Map - Weighted Graph, where each edge carry the distance between two places
